# Infinite Canvas: Backlog

Features and enhancements identified as out of scope for the MVP according to `docs/SPEC.md` Section 1. Parked here for future consideration post-launch.

## Parked Features

1. **User Accounts & Social Features**
   - User profiles, handles, avatars, follow/friend lists, activity feeds.
   - Cross-device sync via authenticated account login.

2. **Advanced Tools & Brushes**
   - Textured brushes, watercolor, airbrush, calligraphy pens.
   - Geometric shapes (rectangles, circles, lines, polygons).
   - Text tool with system and custom fonts.
   - Flood fill / paint bucket tool.
   - Eraser tool for erasing other users' strokes (MVP only supports undoing own last stroke).

3. **Layers & Canvas Structure**
   - User or tile layers with opacity and blending modes.
   - Private canvas overlays or personal notebooks.
   - Multiple independent canvases / themed rooms / private canvases.

4. **Monetization & Economy**
   - Ink refill purchases or subscriptions.
   - Premium brush packs, colors, or cosmetics.

5. **Platform Wrappers**
   - Native iOS and Android packages via Capacitor / React Native.

6. **Seasonal / Time Mechanics**
   - Canvas resets, seasonal snapshots, decay/fade mechanics over time.
